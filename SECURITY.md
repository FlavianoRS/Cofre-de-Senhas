# Política de segurança

## Versões suportadas

A versão mais recente da branch `main` recebe correções de segurança. Versões anteriores podem deixar de ser suportadas após uma atualização.

## Relatando uma vulnerabilidade

Não publique vulnerabilidades, chaves, credenciais ou dados pessoais em issues abertas.

Use o recurso **Report a vulnerability** do GitHub para enviar um aviso privado:

https://github.com/FlavianoRS/Cofre-de-Senhas/security/advisories/new

Inclua, quando possível:

- versão ou commit afetado;
- aparelho e versão do sistema operacional;
- passos mínimos para reproduzir;
- impacto observado;
- sugestão de correção, se disponível.

O recebimento será confirmado assim que possível. A vulnerabilidade será analisada antes de qualquer divulgação pública, e os créditos do pesquisador serão preservados quando solicitado.

## Escopo sensível

Problemas relacionados a criptografia, derivação de chave, autenticação, biometria, armazenamento local, permissões Android, logs contendo dados pessoais e assinatura de releases devem ser tratados como relatórios privados.
